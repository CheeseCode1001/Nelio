Shape
A pill (icon + coloured title) that grows into a blob when there is more to say: description, actions, a timestamp or a progress bar. It shrinks back to the pill before leaving.
Where
Desktop: top right under the header. Mobile: top, full width, above the content. Max 3 stacked; older ones collapse to pills.
Timing
Success/info 4 s, warning 6 s, error stays until dismissed or acted on. Hover pauses. Loading turns into success/error with update().
Sound
Pop on enter; success, error and notify play their own sound (see below).
Code
goey-toast: <GooeyToaster position="top-right" /> once in the app shell, then gooeyToast.success({ title, description, action }). Import 'goey-toast/styles.css'. Fill #FFFFFF (light) / #1A1A1A (dark).

Agent avatars · bot-avatars

Each agent is a plush bot with its own shape and colour.

States
default (idle: blinks, looks, breathes) · working (while a job runs) · sleeping (paused agent). Reduced motion: still frame.
Look
Bright plush with a satin sheen: 18 shapes, each agent one shape + one brand colour; Nelio AI is the black cloud, a cousin of the mascot.
Settings
Colour bots: brightness 1.25, saturation 2.1, shadow 0.6, highlight 1.9, lightFront 55, shine 2, sheen 1.8, rim 1.2, backSoftness 0.6. Black cloud: brightness 0.85, saturation 1.2, shadow 1.1, highlight 1.6, shine 1.8, sheen 0.45, rim 0.9, backSoftness 0.4.
Code
<BotAvatar type="blob" color="#FF4FB8" state={running ? 'working' : 'default'} size={40} /> from bot-avatars. Canvas 2D, no WebGL.

Stickers · fun-isometric

24 animated isometric stickers in the Nelio palette, used for empty states and spot moments.

Palette
Nelio slots: main #2F5BFF · gold #FFD43B · tint #DCE5FF · ok #B6F24A · hot #FF4FB8 · deep #0B0B14. Flat fills, 5 px ink outline, slab side, no gradients.
Use
Empty states (one sticker, 160–200 px), onboarding steps, upsell cards and success moments. Never more than one per card.
Code
Copy kit/fun.ts + motions.ts + Sticker.tsx into src/stickers; <Sticker icon={mailbox} palette={NELIO} size={180} />. Reduced motion shows the still frame.
Credit
Made with fun-isometric by Kelvin Adithya (x.com/KelvinAdithya), heavily inspired by Slush (slush.app), more at skills.klvn.dev/fun-isometric

Loading (pulse)
How
Skullet measures the real component and draws a bar per text line and a block per image or button, so the skeleton is the exact shape of what loads.
Animation
animation: "pulse" (opacity), never the shimmer: shimmer is a moving gradient and Nelio is flat colour only.
Code

Plays onUndo, dismiss, back
Recipe (WebAudio)sine 660 → 440 Hz, 90 ms
Feel
Short (under 0.4 s), soft and round: sine/triangle tones, 20–40% of system volume. Fun, never loud.
When
Only on a direct action or a toast. Never on hover, scroll, page load or while a video plays. Max one sound per 80 ms.
Control
Settings › Appearance › Interface sounds (on by default, volume slider). Off when Reduce motion is on.
Code
One useSound() hook: a shared AudioContext created on the first tap, each token a small synth function. No audio files to load.
