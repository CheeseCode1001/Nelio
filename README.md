# Nelio

AI social media operating system for creators, businesses and agencies. AI agents research, plan, clip, edit, schedule, publish and optimize content under explicit licensing, approval and spending controls. Authorized video clipping is the flagship feature.

## Status
**Design phase (Master Prompt 1).** No production code yet. Implementation (Master Prompt 2) begins only after explicit design approval.
